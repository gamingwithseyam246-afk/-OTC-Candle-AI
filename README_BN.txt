OTC Candle AI — প্রাথমিক Android project

এটি একটি অসম্পূর্ণ starter project, প্রস্তুত APK নয়।
এতে শুধু Android screen-capture permission dialog দেখানোর প্রাথমিক ব্যবস্থা আছে।
এখনো Quotex candle শনাক্তকরণ, OHLC extraction, OCR, বা UP/DOWN/WAIT signal engine নেই।
Build workflow GitHub Actions-এ debug APK তৈরি করার চেষ্টা করবে, কিন্তু build/test সফলতার নিশ্চয়তা নেই।
